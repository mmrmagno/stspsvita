# libGDX 1.9.5 Vita backend

A libGDX backend in Java. TeaVM compiles it together with the game, and it talks to the
Vita through the C functions in `native/src/glue/` with TeaVM's `@Import` and `@Include`.

It implements the 1.9.5 interfaces, the version inside the game jar. The `Graphics` and
`Input` interfaces changed in later libGDX versions.

| Class | What it does |
|---|---|
| `VitaApplication` | Main loop, lifecycle, postRunnable queue |
| `VitaGraphics` | vitaGL context, fixed 960x544 |
| `VitaGL20` | Bindings into vitaGL, generated by `tools/gen_gl.py` |
| `VitaInput` | Controller, front touch and the Vita keyboard |
| `VitaAudio` | OpenAL Soft, streamed OGG music and preloaded sounds |
| `VitaFiles` | Assets, saves and preferences under `ux0:data/stsvita/` |
| `VitaPreferences` | Stub, the game reads its own files through `VitaFiles` |
| `VitaNet` | Always offline |

`stubs/` replaces desktop-only libraries from the jar, see its README.
